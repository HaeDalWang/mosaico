# 자동 모자이크 — run.py 사용법

컬러 일러스트에서 음경, 음낭, 여성기, 항문을 찾아 18px 모자이크로 가리는 스크립트다. 인터넷 연결이나 AI 서비스 없이 내 컴퓨터에서만 돈다. 원본 파일은 건드리지 않는다.

## 0. 받기

### 에이전트에게 맡기기 (권장)

1. 공유받은 모델 파일을 다운로드 폴더에 받아둔다.
2. 평소 쓰던 에이전트를 열고 `처음_붙여넣을_말.md`의 상자 안 글을 그대로 붙여넣는다.

내려받기, 모델 파일 넣기, 설치, 기존 작업과의 연결까지 에이전트가 한다.

### 직접 하기

1. https://github.com/HaeDalWang/mosaico 에서 초록색 **Code** 버튼 → **Download ZIP**을 눌러 받고 압축을 푼다.
2. 공유받은 모델 파일을 `models\v50` 폴더에 넣는다. 이 폴더는 이미 만들어져 있다. zip 파일째로 넣어도 된다.

## 1. 가장 쉬운 방법

### 에이전트에게 시키기 (Codex, Claude Code)

1. 이 폴더에서 에이전트를 연다.
2. **"모자이크 해줘"** 라고 한다.

처음이면 에이전트가 설치를 하고, 그림이 보통 어디서 오고 결과를 어디로 보내는지 몇 가지를 묻는다. 답은 `작업환경.md`에 저장되어 다음부터는 묻지 않는다. 에이전트가 따르는 지시는 `AGENTS.md`에 있다.

**작업 묶음마다 새 대화로 시작하는 것을 권한다.** 대화가 아주 길어지면 에이전트가 처음 지시를 덜 정확히 따를 수 있다. 에이전트가 이상하게 굴면 대화를 새로 열고 다시 "모자이크 해줘"라고 하면 된다.

### 더블클릭으로 하기 (윈도우)

1. 처음 한 번만 `install.bat`을 더블클릭한다. 몇 분 걸리고, 끝에 `[준비 완료]`가 나오면 된다.
2. 가릴 그림을 `input` 폴더에 넣고 `run.bat`을 더블클릭한다.
   그림이나 폴더를 `run.bat` 위로 끌어다 놓아도 된다.

Python 3.12가 없으면 `install.bat`이 실패한다. [python.org](https://www.python.org/downloads/)에서 3.12를 설치하고, 설치 첫 화면에서 **"Add python.exe to PATH"를 체크**한 뒤 다시 실행한다.

## 2. 폴더 구성

```
├── 처음_붙여넣을_말.md        처음 한 번 에이전트에게 붙여넣는 글
├── AGENTS.md, CLAUDE.md      에이전트용 지시
├── install.bat, run.bat      윈도우 더블클릭용
├── setup_env.py              설치 (가상환경, 라이브러리, 점검)
├── run.py, mosaic.py         모자이크 처리
├── check.py                  설치 점검
├── test_workspace.py         자체 시험
├── measure.py                사람이 가린 전/후 쌍과 비교
├── requirements.txt
├── models/v50/               공유받은 모델 파일을 넣는 곳
├── input/                    가릴 그림을 넣는 곳
└── out/                      결과. 직접 확인이 필요한 것은 out/hold/
```

모델 파일(`.pt`)은 저장소에 들어 있지 않고 따로 공유받는다. 그래픽카드는 필요 없다.

## 3. 터미널에서 직접 실행

설치는 처음 한 번만 한다. 아래는 윈도우 기준이고, 맥은 `py -3.12`를 `python3.12`로, `.venv\Scripts\python`을 `.venv/bin/python`으로 바꾼다.

```
py -3.12 setup_env.py
```

실행할 때 아무것도 적지 않으면 `input` 폴더를 처리한다. 그림이나 폴더 경로를 뒤에 적어도 된다. 폴더를 주면 안의 png, jpg, jpeg, webp를 전부 처리한다.

```
.venv\Scripts\python run.py
.venv\Scripts\python run.py "C:\그림\사진1.png" "C:\그림\작업할것"
```

- 경로에 공백이나 한글이 있으면 큰따옴표로 감싼다.
- 처음 실행할 때는 모델을 읽느라 몇 초 걸린다.

## 4. 결과 보는 법

그림마다 한 줄씩 나오고, 맨 끝에 합계와 다음에 할 일이 나온다.

```
[통과] 사진1.png: 사진1_model.png | 가림 65668px | 검출 pussy@480:0.89, ...
[보류] 사진2.png: 사진2_model.png | 가림 ...px | ... | 검출 불안정(해상도 한 곳에서만 잡힘): penis
[검출 없음] 사진3.png: 저장 안 함, 확인 필요

합계: 통과 1, 재시도 후 통과 0, 보류 1, 검출 없음 1, 오류 0
끝난 결과: ...\out
직접 열어서 확인할 것 (...\out\hold): 사진2.png
부위를 못 찾아 저장하지 않은 것 (가릴 것이 없는 그림인지 직접 확인): 사진3.png
참고: [통과]는 검출 모델의 재검사에 걸리지 않았다는 뜻이고, 노출이 전혀 없다는 보증은 아니다.
```

| 표시 | 뜻 | 결과 파일 | 할 일 |
|---|---|---|---|
| `[통과]` | 가린 뒤 다시 검사했을 때 깨끗했다 | `out/원본이름_model.png` | 없음 |
| `[재시도 후 통과]` | 처음엔 부위가 다시 보여서, 더 넓게 가려 해결했다 | `out/원본이름_model.png` | 없음. 다만 평소보다 넓게 가려졌을 수 있다 |
| `[보류]` | 다시 가려도 부위가 보이거나, 검출이 불안정했다 | `out/hold/원본이름_model.png` | 직접 열어서 확인한다 |
| `[검출 없음]` | 아무 부위도 못 찾았다 | 저장하지 않음 | 가릴 게 없는 그림인지, 놓친 건지 직접 확인한다 |
| `[오류]` | 파일을 못 읽었거나 저장·검증에 실패했다 | — | 표시된 이유를 본다 |

- 결과는 항상 PNG로 저장된다. 원본이 jpg여도 마찬가지다.
- 같은 이름의 결과 파일이 이미 있으면 덮어쓴다.
- `검출 pussy@480:0.89`는 "480 크기로 봤을 때 여성기를 0.89의 확신으로 찾았다"는 뜻이다.
- 중간에 `WARNING`으로 시작하는 줄이 나와도 결과에는 영향이 없다.

## 5. 안에서 하는 일

1. 그림을 480, 544, 640 세 가지 크기로 줄여서 각각 부위를 찾고, 찾은 영역을 합친다.
2. 합친 영역을 18px 넓힌 뒤 18px 모자이크를 입힌다. 격자는 이미지 좌상단 (0,0)에서 시작하고, 칸 색은 그 칸의 평균이다.
3. 가린 결과물을 같은 모델로 다시 검사한다. 부위가 0.7 이상의 확신으로 다시 보이면 불합격이다.
4. 불합격이면 다시 보인 부위를 추가하고 더 넓게 가려서 재검사한다. 두 번까지 다시 시도한다.
5. 저장한 뒤, 이미지 크기가 원본과 같은지와 가림 영역 밖 픽셀이 원본과 완전히 같은지 확인한다.

## 6. 값 조정

파일을 메모장으로 열어 숫자를 바꾸고 저장한 뒤 다시 실행한다.

| 값 | 위치 | 기본값 | 바꾸면 |
|---|---|---|---|
| `TARGET_CLASSES` | `run.py` 위쪽 | penis, testicles, anus, pussy | 가릴 부위. 유두도 가리려면 `"nipples"`를 추가한다 |
| `IMAGE_SIZES` | `run.py` 위쪽 | 480, 544, 640 | 그림을 줄여서 보는 크기. 32의 배수로 적는다. 개수를 늘리면 누락이 줄고 시간이 늘어난다. 700 이상은 넣지 않는 것을 권한다 |
| `ATTEMPTS` | `run.py` 위쪽 | (0.25, 18), (0.10, 27), (0.05, 36) | 괄호 하나가 시도 한 번이다. 앞 숫자는 검출 기준(낮출수록 애매한 것도 잡음), 뒤 숫자는 넓히는 px(올릴수록 넓게 가림) |
| `RECHECK_FAIL_CONF` | `run.py` 위쪽 | 0.7 | 재검사 불합격선. 낮추면 더 깐깐해져서 재시도와 보류가 늘어난다 |
| `BLOCK_PX` | `mosaic.py` 위쪽 | 18 | 모자이크 한 칸의 크기 |

가장자리가 자주 삐져나오면 `ATTEMPTS` 첫 괄호의 18을 27로 올린다. 너무 넓게 가려지면 9로 내린다.

## 7. 알아둘 한계

- **음모는 못 잡는다.** 모델에 그 항목이 없다.
- **흑백 그림과 만화, 실사는 못 잡는다.** 모델 제작자가 밝힌 제한이다.
- **`[통과]`는 "모델 눈에 깨끗하다"는 뜻이지 노출이 없다는 보증이 아니다.** 검사도 같은 모델이 하므로, 모델이 아예 못 보는 구도의 부위는 통과로 나온다. 중요한 작업물은 직접 한 번 본다.
- **기본값은 예시 1쌍으로 맞춘 값이다.** 그 한 장에서는 사람이 가린 영역의 92.0%를 덮었고, 가린 영역의 6.6%가 사람 작업 범위 밖이었다. 다른 그림에서 같은 수준이 나오는지는 아직 확인하지 못했다.
- 윈도우에서의 설치와 실행(`install.bat`, `run.bat` 포함)은 아직 직접 돌려보지 못했다. 맥에서만 확인했다.

## 8. 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| Python 3.12가 없다고 나온다 | Python 설치 때 "Add python.exe to PATH"를 체크했는지. 다시 설치하면서 체크한다 |
| `No module named 'ultralytics'` | `install.bat`을 끝까지 실행했는지. 터미널에서 직접 할 때는 `.venv\Scripts\python`으로 시작했는지 |
| 모델 파일을 못 찾는다고 나온다 | `models\v50\ntd11_anime_nsfw_segm_v5.pt` 경로와 파일명이 정확한지 |
| `처리할 이미지가 없습니다.` | 경로가 맞는지, 확장자가 png/jpg/jpeg/webp인지 |
| 전부 `[검출 없음]`으로 나온다 | 흑백이나 만화풍 그림인지. 컬러 일러스트인데도 그러면 `ATTEMPTS` 첫 괄호의 0.25를 0.10으로 낮춰본다 |
